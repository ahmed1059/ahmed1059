# الرفع على Railway أو Render

الخادم نفسه محلياً وعلى السحابة:

```text
uvicorn Core_Engine.app:app --host 0.0.0.0 --port $PORT
```

هذا السطر مكتوب في `Procfile`. المنصة تضع رقم المنفذ في `PORT`.

## ما يُحفظ خارج الكود

الكود على Git. البيانات ليست في المستودع إن بقيت قاعدة المدرسة محلية. على السحابة يلزم قرص دائم لأن نظام الملفات العادي يُمسح عند كل نشر.

اربط القرص بمجلد واحد، مثلاً `/data`، وانسخ إليه محتوى `School_Data` قبل أول تشغيل حي: القاعدة، و`signatures`، و`council_minutes.json`، و`imports`.

ثم اضبط:

```text
DATABASE_PATH=/data/School_Data/school_1059.db
```

المسار النسبي يُحسب من جذر المشروع. المسار المطلق يُستخدم كما هو. مجلد النسخ من الإعدادات يقع بمستويين فوق ملف القاعدة، فيصبح `/data/backups` مع المثال أعلاه، فيبقى على القرص نفسه.

التوقيعات ومحضر المجالس لا تتبع `DATABASE_PATH`. تبقى تحت `School_Data` في نسخة التشغيل. لذلك القرص الدائم هو المجلد كاملاً، لا ملف القاعدة وحده.

## Railway

1. أنشئ مشروعاً فارغاً.
2. اربطه بمستودع GitHub الذي فيه هذا المشروع. جذر التشغيل هو جذر المستودع، حيث يوجد `Procfile` و`Core_Engine`.
3. أضف Volume واربطه بالمسار `/data`.
4. في المتغيرات أضف `DATABASE_PATH=/data/School_Data/school_1059.db`.
5. انشر. Railway يقرأ `Procfile` ويثبت `requirements.txt`.
6. من إعدادات الخدمة انسخ رابط النطاق العام. افتح `/login.html` ثم `/app-journey.html`.

بعد أول نشر انسخ ملفات `School_Data` المحلية إلى `/data/School_Data` على القرص قبل اعتماد الرابط للعمل اليومي.

## Render

1. أنشئ Web Service من المستودع نفسه.
2. بيئة Python. أمر البناء: `pip install -r requirements.txt`.
3. أمر التشغيل، إن لم يقرأ `Procfile` وحده:

```text
uvicorn Core_Engine.app:app --host 0.0.0.0 --port $PORT
```

4. أضف Disk واربطه بـ `/data`، ثم المتغير `DATABASE_PATH` كما في Railway.
5. بعد النشر افتح الرابط الذي يعطيه Render ثم `/login.html`.

## بعد الرفع

الهوامش في نافذة الطباعة تبقى «بلا»، ورسومات الخلفية مفعّلة. تعديل Python يحتاج إعادة نشر. تعديل HTML يصل مع النشر التالي ولا يحتاج تغييراً في أمر التشغيل.

لا تضع كلمة المرور في المستودع. الحساب يُفتح بالهوية وكلمة المرور المحفوظة في القاعدة التي نُقلت إلى القرص.
