# الوحدة الثانية — توحيد الهوية والقائمة الجانبية (المحطات الأربع)

**الحالة:** جاهزة للمعاينة  
**الفرع:** `cursor/unit2-four-stations-nav-b9be`  
**الأساس:** اعتماد الوحدة 1 + الشروط الثمانية  
**نطاق التعديل:** `app-journey.*` (+ رموز اختصار في `responsive.css` للشريط الضيق فقط)  
**ممنوع لمسه:** `erp-nav.js` / `erp-suite.js` / `dashboard.html`

---

## ماذا تغيّر

### 1) القائمة الجانبية
أربع محطات بمسمياتها الرسمية فقط:

1. التأسيس والإعدادات المركزية (`foundation`)
2. الخطط المدرسية (`planning`)
3. السجلات والمحاضر والشواهد (`registers`)
4. القياس والاعتماد المدرسي (`measurement`)

أُزيلت مراحل: تخطيطي / إعداداتي / مهامي / تنفيذي / طباعتي / متابعتي / شواهدي كعناوين عليا.

### 2) خريطة المحطات (`#view-home`)
أربع بطاقات بنفس المسميات والترتيب المنطقي: تأسيس ← تخطيط ← سجلات ← قياس.

### 3) الشريط السفلي
`مكتبي | تأسيس | خطط | سجلات | قياس | المحطات` مع إبراز المحطة النشطة عبر `aria-current`.

### 4) موجّه الكروم (`syncChrome`)
خريطة `STATION_BY_VIEW` تربط كل عرض بمحطته وتفتح لوحة واحدة فقط.

### 5) رابط النظام السابق
نُقل إلى أسفل الشريط الجانبي بأسلوب هادئ (نص باهت صغير)، مع ملاحظة مراجعة فقط في المكتب — بلا مزاحمة للمحطات.

### 6) SSOT
لا اعتماد على `board1059.*` / `localStorage` للبيانات في مسار الرحلة؛ الجلسة عبر `sessionStorage.sessionUser` والبيانات عبر APIs/`Core_Engine/app.py`.
