# بروتوكول الفحص الاستكشافي الآلي قبل التسليم

**الغرض:** منع تسليم تحديثات `app-journey.*` قبل التحقق الآلي من العزل البصري، التكيف، الطباعة، وخلو Console من الأخطاء الصامتة.

**الأداة:** `scripts/smoke_journey_exploratory.mjs` (Playwright headless)

---

## ما الذي يُفحص؟

1. **تنقل متسلسل + عشوائي** بين المحطات الأربع وبنودها الفرعية.
2. **عزل بصري:** شاشة `.aj-view` واحدة ظاهرة؛ لا تسرب `#view-desk` خلف المحطات.
3. **محتوى غير فارغ:** ارتفاع ومعاينة نصّية للشاشة النشطة.
4. **تكيف:** عرض جوال `390×844` وعرض مكتب `1366×768`.
5. **طباعة:** فتح معاينة خطة الزيارات (`#aj-visit-plan-print`) ثم `emulateMedia('print')` والتأكد من ظهور `#aj-print-stage` وعدم ظهور بطاقة الموهوبين بالخطأ.
6. **رصد صامت:** أخطاء Console + استجابات HTTP 4xx/5xx (مع تجاهل `/ws/events` بعد التحويل للاستطلاع).

---

## التشغيل المحلي

```powershell
# من جذر المستودع بعد تشغيل الخادم على 8060
python Core_Engine/app.py
```

في طرفية أخرى:

```bash
cd scripts
npm install
cd ..
BASE_URL=http://127.0.0.1:8060 \
SMOKE_NATIONAL_ID=1046940365 \
SMOKE_PASSWORD="..." \
node scripts/smoke_journey_exploratory.mjs
```

- إن تُركت `SMOKE_PASSWORD` فارغة يُقرأ محلياً `School_Data/.initial_admin_password` (غير متتبَّع في Git).
- التقرير: `artifacts/smoke/smoke-report.json`
- لقطات: `artifacts/smoke/viewport-390.png` و`viewport-1366.png`
- رمز الخروج `0` = نجاح · `1` = فشل يجب إصلاحه قبل رابط المعاينة.

---

## قاعدة التسليم للوكيل

قبل إرسال رابط معاينة لأي تحديث مستقبلي على الرحلة:

1. شغّل السكربت أعلاه حتى ينجح.
2. إن فشل: أصلح السبب (عزل / طباعة / شبكة / Console) وأعد التشغيل.
3. لا تُرسل رابط المعاينة وفي التقرير `ok: false`.

---

## نتيجة التشغيل الأول (وحدة 3)

- نجح الفحص (`ok: true`) بعد إصلاح `softFetch` ليرسل `X-Session-Token` (كان يسبب 401 صامتة على `/api/councils` و`/api/noor/staff`).
- طباعة خطة الزيارات تعرض العنوان الصحيح وليس بطاقة الموهوبين.

## توسيع لاحق (اختياري)

- إضافة مسارات طباعة أخرى (بطاقة برنامج، محضر، شواهد).
- ربط السكربت كـ check في CI على PR.
- زرّ `SMOKE_SEED` ثابت لإعادة إنتاج جولة عشوائية معيّنة.
