## 1) العزل البصري الصارم

- كل رابط محطة/فرعي يفتح عرضاً مستقلاً داخل `.aj-main`.
- `isolateViews()` يخفي كل `.aj-view` غير النشط (`hidden` + `display:none` + إزالة `.is-active`).
- أزرار المحطات الأربع تنتقل إلى `#view-station-*` فلا يبقى `#view-desk` أو بطاقاته في الخلفية.
- إغلاق أدراج الظل المطلقة في وضع الميدان (لا ألواح طافية فوق المحتوى).

## 2) ترتيب القوائم كرحلة عمل متسلسلة

### التأسيس والإعدادات المركزية
بيانات المدرسة → الترويسة والأختام → الاستيراد من نور → سجل المنسوبين → قوائم الطلاب → التشكيل القيادي → تشكيل اللجان والمجالس → الحسابات والصلاحيات → التقويم والمناسبات → النسخ/التدقيق/الفحص (مع أزرار الصيانة والتسكين داخل `#view-system-care`).

### الخطط المدرسية
الخطة التشغيلية → الخطط الذكية → إضافة برنامج/مبادرة → التوزيع الزمني على الفصلين.

### السجلات والمحاضر والشواهد
مركز التنفيذ → الخطة السنوية للزيارات → الزيارات الصفية → تسليمات المعلمين → شواهد البرامج والبيئة → الرخص المهنية → شواهد الممارسات → معرض الشواهد الشامل.

### القياس والاعتماد المدرسي
مؤشرات الأداء (SSOT) → ملف التدريب والقياس (نافس) → التقويم الذاتي والاعتماد الخارجي (ETEC).

**ملاحظة:** «التنبيهات ومهام اليوم» تبقى في شاشة مكتبي فقط.

## 3) التكيف التلقائي (رابط واحد)

| الوضع | الشرط | السلوك |
|--------|--------|--------|
| الميدان السريع | `< 1024px` | بطاقات رأسية، أزرار لمس كبيرة، رفع شاهد سريع، شريط سفلي للمحطات |
| الإدارة والطباعة | `≥ 1024px` | قائمة جانبية كاملة، جداول تفصيلية، معاينة/طباعة A4 كما هي |

الكشف عبر `matchMedia('(max-width: 1023px)')` + أصناف `aj-mode-field` / `aj-mode-admin`.

## 4) الطباعة (تحديث معاينة PR #7)

- `#aj-print-stage` و`#aj-print-stage-page` تُجبر على `display:block` / `visibility:visible` في `@media print`.
- أُزيل فخ `height:0` الذي أنتج صفحة بيضاء في بعض المتصفحات.
- الرسالة الإرشادية الخضراء تُزاح لأسفل أثناء المعاينة حتى لا تغطي زر «طباعة».
- زر الطباعة و`beforeprint` يستدعيان تجهيز المرحلة ثم `window.print()`.
- `event-bus.js`: محاولة WebSocket واحدة ثم التحويل الصامت إلى الاستطلاع دون إعادة اتصال متكررة.
- إصلاح تعارض `id="aj-plan-print"` بين خطة الزيارات وبطاقة البرنامج؛ طباعة الزيارات تستخدم `aj-visit-plan-print` فقط.
- بروتوكول دخان استكشافي: `scripts/smoke_journey_exploratory.mjs` + `docs/unit3_smoke_protocol.md` (يُشغَّل قبل أي رابط معاينة).
- إصلاح `softFetch` لإرسال توكن الجلسة (اكتشاف الفحص الآلي).
