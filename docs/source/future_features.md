# التوسعات المستقبلية (v2.0)

## 1. قائمة منسدلة عند (+)
عند إضافة بند جديد، تظهر قائمة:
- مهمة من بنك المهام (مصفّاة حسب الدور + الأسبوع + الفصل)
- بند مخصص (كتابة يدوية)
- استيراد من خطة أخرى

## 2. خطط بتواريخ حقيقية
- ملف holidays_1448.json للإجازات والمناسبات
- دالة get_week_days() في calendar_engine
- استبعاد أيام الإجازات تلقائيًا

## 3. صورة المستخدم
- رفع صورة من الإعدادات
- إطار دائري CSS
- تخزين في School_Data/photos/{user_id}.jpg

## 4. كلمة جاهزة
- قوالب في Core_Engine/word_templates/
- استبدال المتغيرات: {user_name}, {role_title}, {school_name}
- إدراج الصورة + الاسم + الوظيفة تلقائيًا

## 5. لاحقًا
- رسائل إشعار داخلية
- تقارير إحصائية
- تصدير PDF
- تطبيق جوال

---

## 6. الإطار المطبوع العلوي والسفلي
- إطار ثابت يتكرر في كل صفحة مطبوعة.
- الشعارات (رؤية 2030 + وزارة التعليم) في الأعلى.
- النص الرسمي في المنتصف.
- خط تركوازي أفقي في الأعلى.
- خط أخضر أفقي في الأسفل.
- سهام زخرفية على الأطراف.
- التقنية: table مع thead/tfoot (الأكثر موثوقية للطباعة).
- ملف CSS منفصل: print-frame.css

## 7. تصدير Word (.docx)
- نهج هجين: HTML للطباعة، Word للتعديل.
- مكتبة: python-docx.
- قالب Word مُصمّم مسبقًا (templates/plan_template.docx).
- Endpoint: GET /api/export-word/{plan_id}.
- زر في الواجهة: "تصدير Word".
- يشمل: الرؤية، الرسالة، القيم، الأهداف، الجداول.

## 8. أسلوب الأهداف الاستراتيجية
- بطاقات مرئية (بدل JSON).
- checkbox لكل هدف (اختيار/تعطيل).
- حقل نصي للهدف.
- قائمة مؤشرات KPIs قابلة للإضافة/الحذف.
- قائمة برامج قابلة للإضافة/الحذف.
